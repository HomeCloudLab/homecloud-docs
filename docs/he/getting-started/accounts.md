# פתיחת חשבון

**חשבון** הוא ה-workspace המבודד שלכם ב-HomeCloud. Buckets, תורים, מסדי נתונים, אפליקציות ו-Access Keys חיים בתוכו.

## הרשמה עצמית

אם הרשמה ציבורית מופעלת בפלטפורמה שלכם:

1. פתחו `https://console.{apex}/open-account` (גם מקושר מדף ה**התחברות**).  
2. הזינו **אימייל** ובקשו קוד אימות.  
3. הזינו את ה-**OTP בן 6 הספרות** מהאימייל.  
4. בחרו **שם חשבון**, **שם משתמש** ו**סיסמה**. ה-slug של החשבון נגזר מהשם.  
5. נכנסים לקונסול כ**בעלי החשבון**.

ההרשמה יוצרת tenant **ריק**: החשבון ועם משתמש הבעלים. לא נוצרים אוטומטית buckets, מסדי נתונים או אפליקציות — מוסיפים אותם כשצריך.

## הצטרפות לחשבון קיים (הזמנה)

1. פתחו את קישור ההזמנה מהאימייל (`/invite/...`).  
2. התחברו או צרו משתמש לפי ההנחיות.  
3. קבלו את ההזמנה. **תפקיד הקונסול** שלכם (Owner / Admin / Developer / Viewer) נקבע על ידי מי שהזמין.

בעלים ואדמינים מזמינים אנשים מאוחר יותר תחת **Account → Members** (או **IAM → Users**, לפי גרסת הקונסול).

## התחברות

1. עברו אל `https://console.{apex}/login`.  
2. הזינו מזהה חשבון (מספר חשבון או כינוי), שם משתמש וסיסמה.  
3. השלימו **MFA** אם מופעל למשתמש (TOTP או passkey).  

אחרי ההתחברות רואים את לוח הבקרה. אם שייכים לכמה חשבונות, השתמשו ב**מחליף החשבונות** בסרגל העליון.

## דברים ראשונים אחרי הרשמה

| שלב | למה |
|-----|-----|
| הפעילו MFA למשתמש הבעלים | מגן על גישת הקונסול |
| הזמינו חברי צוות עם התפקיד הנכון | Viewer לא משנה משאבים; Developer יכול לבנות |
| צרו [Access Key](access-keys.md) | נדרש ל-CLI / SDK / CI |
| עברו על [שימוש בקונסול](console.md) | למדו איפה כל שירות חי |

## CLI: רשימה והחלפת חשבונות

```bash
homecloud login --username alice
homecloud accounts list
homecloud accounts switch my-team
```

Access Keys תמיד שייכים לחשבון **אחד**. כשמריצים `homecloud configure` עם מפתח, החשבון הזה נבחר אוטומטית לפקודות data-plane.

## חשבונות שנוצרו על ידי אדמין פלטפורמה

אם מנהל פלטפורמה יצר עבורכם את ה-tenant, ייתכן שבחר מצב bootstrap (bare / minimal / full). עדיין מתחברים באותו אופן. בקשו ממנו את כתובת הקונסול ואת שם המשתמש הראשוני.
