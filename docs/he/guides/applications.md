# Applications

Applications פורסות **מחסנית מוכנה** מתבנית כדי שלא תחברו ידנית כל אובייקט Kubernetes. השתמשו בהן כשרוצים צורה מוכרת (API, אתר, worker) עם פעולות קונסול ללוגים, מדדים, דומיינים והגדרות.

| פריט | ערך |
|------|--------|
| Console | **Applications** → `/console/applications` |
| CLI | `homecloud apps list` (ניהול; יצירה/עדכון בעיקר בקונסול) |

## תבניות

| תבנית | שימוש טיפוסי |
|-------|--------------|
| **api-only** | שירות API בצד שרת |
| **fullstack** | מחסנית בסגנון frontend + API |
| **static-site** | נכסים סטטיים (לעיתים יחד עם דפוסי אירוח אתר SO) |
| **worker** | צרכן רקע / תהליך משימה |

משתני סביבה ורכיבים מדויקים תלויים בגרסת התבנית שמוצגת באשף היצירה.

## הליכה בקונסול

### יצירה

1. פתחו **Applications** → **Create**.  
2. בחרו תבנית, שם ופרויקט (אם משתמשים ב-[Projects](account.md)).  
3. מלאו הגדרות נדרשות (image, env, משאבים, צירופי דומיין כפי שמתבקש).  
4. צרו והמתינו עד שהרכיבים הופכים לבריאים.

### לשוניות פרטים

אחרי פתיחה, בדרך כלל מקבלים:

| לשונית | מטרה |
|--------|------|
| **Overview** | סטטוס, נקודות קצה, סיכום |
| **Components** | חלקי המחסנית |
| **Resources** | CPU/זיכרון וכפתורים קשורים |
| **Domains** | צירוף hostnames מותאמים |
| **Metrics** | גרפי זמן ריצה כשמופעל |
| **Logs** | הזרמה או שליפת לוגים אחרונים |
| **Settings** | עריכות תצורה |
| **Advanced** | אפשרויות למשתמשים מתקדמים |

השתמשו בפעולות **Operations** (הפעלה מחדש, סנכרון וכו') מהממשק כשהן מוצעות — העדיפו אותן על פני kubectl ידני ליום־2.

### Domains

צרפו דומיין מאומת מ-[Domains](domains.md) כדי שהאפליקציה תהיה נגישה ב-hostname שלכם. תעודות SSL מופיעות תחת [SSL](ssl.md) אחרי הנפקה.

### לוגים ומדדים

- **Logs** — דיבוג קריסות והגדרות שגויות.  
- **Metrics** — מעקב אחרי CPU, זיכרון ואותות ברמת בקשה כשמחסנית הניטור זמינה לחשבון.

## CLI

```bash
homecloud login --username alice
homecloud apps list
```

מחזור חיים עמוק יותר (יצירה/עדכון/מחיקה) הוא console-first היום; השתמשו בממשק לפעולות האלה אלא אם גרסת הפלטפורמה מוסיפה פקודות CLI נוספות.

## מתי להשתמש ב-Applications מול Kubernetes גולמי מול Functions

| צורך | העדיפו |
|------|--------|
| מחסנית תבנית עם פעולות קונסול | **Applications** |
| מניפסטים מותאמים / עומסים חד־פעמיים | **Kubernetes** |
| קוד קצר מונחה־אירועים | **Functions** |
| רק קבצים סטטיים | **אתר SO** (לעיתים מספיק לבד) |

## טיפים

- שמרו סודות ב-[Secrets](secrets.md), לא בשדות הגדרות גלויים כשאפשר.  
- נעצו digests של images מ-[IR](registry.md) לפריסות חוזרות.  
- השתמשו ב-Projects כדי לקבץ אפליקציות קשורות לצוות.
