# דיאגרמות

דיאגרמות ארכיטקטורה ברמת חשבון לתכנון, תיעוד והצגות. כל דיאגרמה היא קנבס בבעלות המשתמש — לא מפת מלאי חיה.

| פריט | ערך |
|------|------|
| קונסול | **דיאגרמות** → `/console/diagrams` |
| הרשאות | `diagrams.read` / `diagrams.create` / `diagrams.update` / `diagrams.delete` |
| דלי נכסים | `so://diagrams-{account_number}/…` (מופיע גם ב־Object Storage) |

## רשימה ויצירה

1. פתחו **דיאגרמות**.
2. **דיאגרמה חדשה** — שם (חובה) ותיאור אופציונלי.
3. פתחו שורה לעריכה בקנבס.

## יסודות העורך

- nodes מסוג **Live** מפנים למשאבי HomeCloud אמיתיים (מסומנים stale אם המשאב נמחק).
- nodes מסוג **Planned** מתארים רכיבים עתידיים בלי ליצור משאבים.
- **טקסט** ו**צורות** (מלבן, אליפסה, frame) להערות וגבולות.
- מצבים: בחירה / הזזה / חיבור; snap, יישור, שכבות, undo/redo, שמירה אוטומטית.
- פלטת פקודות: **Ctrl+K**.
- **ייבוא** אופציונלי של ארכיטקטורת החשבון כ־nodes חיים (הקנבס הריק הוא ברירת המחדל).
- לחיצה כפולה על node חי — פתיחה בקונסול; על טקסט — עריכה inline.

## Present וייצוא

- **Present** — תצוגה במסך מלא לקריאה בלבד של הדיאגרמה החיה.
- **ייצוא PNG / SVG** — כל הקנבס או הבחירה הנוכחית.

## שיתוף (קישורים לצפייה בלבד)

כל מי שיש לו את הכתובת יכול לפתוח **תמונת מצב קפואה** בלי התחברות.

1. בעורך (עם `diagrams.update`) לחצו **שיתוף**.
2. בחרו תוקף: **ללא הגבלה**, **7 ימים** או **30 ימים**; תווית אופציונלית.
3. **צור קישור** — העתיקו את ה־URL מיד (מוצג פעם אחת).
4. הנמענים פותחים `/share/diagrams/{token}` — קנבס בסגנון Present, בלי מעטפת הקונסול.
5. **בטלו** קישור פעיל מאותו דיאלוג.

### משמעות תמונת המצב

- הדף הציבורי מציג את המסמך שנלכד בזמן היצירה (שם, תיאור, nodes, edges, groups, viewport).
- עריכת הדיאגרמה אחר כך **אינה** מעדכנת שיתופים קיימים. צרו קישור חדש לפרסום מחדש.
- צופים ציבוריים לא קוראים ל־API של החשבון לרענון מלאי חי ולא רואים סודות.
- תמונות nodes ב־`so://…` נפתרות דרך URL נכסים המוגבל לטוקן השיתוף.

## IAM

| פעולה | תפקידים אופייניים |
|--------|---------------------|
| רשימה / פתיחה / רשימת שיתופים | `diagrams.read` (owner, admin, developer, viewer) |
| יצירה / עריכה / העלאת נכסים / יצירה וביטול שיתופים | `diagrams.update` (owner, admin, developer) |
| יצירת דיאגרמה | `diagrams.create` |
| מחיקת דיאגרמה | `diagrams.delete` (owner, admin) |

## דלי נכסי SO

תמונות מותאמות ל־nodes מועלות לדלי `diagrams-{account_number}` תחת `{diagram_id}/assets/…`. אפשר לדפדף בו ב־**Object Storage** כמו בכל דלי אחר.

## הפניות במשימות

בכותרת, בפירוט או בדיון של משימות הקלידו `#diagrams` או `#diagrams/<diagram-id>` להשלמה אוטומטית וקישורים.
