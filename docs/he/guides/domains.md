# Domains & DNS

הביאו דומיין משלכם (BYOD) כדי ש-Applications, אתרים ושירותים אחרים יוכלו להשתמש ב-hostnames שאתם שולטים בהם.

| פריט | ערך |
|------|--------|
| Console | **Account → Domains** (גם מופיע כ-**Domains** בקטלוג השירותים) |

## זרימת עבודה

### 1. הוספת הדומיין

1. פתחו **Domains** → **Add domain**.  
2. הזינו את ה-apex שבבעלותכם (למשל `example.com`).  
3. הקונסול מציג רשומת **TXT verification**.

### 2. אימות בעלות

1. אצל ספק ה-DNS שלכם (או ממשק DNS של HomeCloud כשמאוחסן שם), צרו את רשומת ה-TXT בדיוק כפי שמוצגת.  
2. המתינו להתפשטות DNS.  
3. לחצו **Verify** בקונסול.

עד שאימות מצליח אי אפשר לצרף את הדומיין לשירותים.

### 3. ניהול רשומות

אחרי אימות, נהלו רשומות לפי הצורך:

| סוג | שימוש טיפוסי |
|-----|--------------|
| **A / AAAA** | הצבעת hostnames ל-IPs של הפלטפורמה כשמודרכים |
| **CNAME** | הצבעת `www` או מארחי אפליקציה ליעדי פלטפורמה |
| **TXT** | אימות, SPF, DKIM, DMARC |
| **MX** | ניתוב דואר (כשמשתמשים ב-HomeCloud Mail על דומיין מותאם — אם מופעל) |
| **SRV** | רשומות גילוי שירות כשנדרש |

עקבו אחרי הערכים שהקונסול או השירות (deliverability של Mail, צירוף דומיין ל-Application) מדפיסים — אל תמציאו יעדים.

### 4. צירוף לשירות

- **Applications → Domains** — צירוף hostname לאפליקציה  
- **אתר SO** — לעיתים משתמש ב-`{bucket}.web.{apex}`; דומיינים מותאמים תלויים בתמיכת הפלטפורמה  
- **Mail** — פאנל deliverability עשוי לפרסם SPF/DKIM/DMARC לדומיין הדואר  

## טיפים

- שמרו TTL מתון בזמן בדיקות; העלו אותו אחרי שהדברים יציבים.  
- כשאימות נכשל, בדקו רשומות TXT כפולות או שגיאות הקלדה (כולל נקודות בסוף).  
- הסרת דומיין שעדיין מצורף לאפליקציה תשבור ניתוב — נתקו קודם.
