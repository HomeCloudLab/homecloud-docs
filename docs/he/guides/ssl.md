# SSL certificates

עמוד SSL מציג **תעודות TLS** שהונפקו לחשבון (דרך מנהל התעודות של הפלטפורמה). זה בעיקר תצוגה **לקריאה בלבד** כדי לאשר שמארחים מכוסים ולראות תפוגה.

| פריט | ערך |
|------|--------|
| Console | **SSL** → `/console/ssl` |

## מה תראו

- רשימת תעודות (מארחים / secrets)  
- סטטוס ותפוגה  
- קישורים או שמות שמתואמים ל-Ingress / צירופי דומיין  

בדרך כלל **לא** מעלים כאן קבצי תעודה גולמיים ל-hostnames סטנדרטיים של Application או קונסול — הפלטפורמה מבקשת ומחדשת תעודות כשדומיינים מצורפים נכון.

## זרימה טיפוסית

1. אמתו וצרפו hostname תחת [Domains](domains.md) / דומייני Application.  
2. המתינו עד שהתעודה הופכת ל-Ready.  
3. אשרו בעמוד **SSL**.  
4. פתחו `https://your-host` ואמתו בדפדפן.

## פתרון בעיות

| תסמין | מה לבדוק |
|-------|----------|
| תעודה תקועה ב-Pending | DNS עדיין לא מצביע על הפלטפורמה; אתגר HTTP-01/DNS-01 נכשל |
| מארח שגוי מכוסה | צירוף דומיין ל-Application / Ingress הלא נכון |
| תפוגה בקרוב | הפלטפורמה אמורה לחדש אוטומטית; אם לא, פנו למפעיל |
