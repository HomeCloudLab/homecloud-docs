# משימות (Tasks)

משימות הוא מעקב עבודה תפעולי לחשבון (שם המוצר: **Tasks**). משמש להקצאה, תאריכי יעד, סטטוסים, תוויות וקישורים ל-Compute / MDB / דומיינים — לא כתחליף ל-Jira.

| פריט | ערך |
|------|------|
| קונסול | **משימות** → `/console/tasks` |
| מפתחות | `TASK-{n}` לכל חשבון |
| אחסון | Postgres של מישור הבקרה (לא משאב Orchestrator) |
| התראה | אימייל דרך **noreply** של הפלטפורמה — רק למי שיש תפקיד בפריט |
| ממשק חי | רמז SSE מ-Realtime Gateway; REST הוא מקור האמת |

## בקונסול

### יצירה

1. פתחו **משימות** → **משימה**.  
2. כותרת, גוף, סוג, מוקצה אופציונלי, תאריך יעד אופציונלי, ותוויות (בחירה מקיימות או שם חדש). הפירוט הוא Markdown: יציאה מהשדה מציגה תצוגה; הגובה קבוע עם גלילה.  
3. מדף פרטי Compute, MDB או דומיין, **משימה** ממלא את המשאב מראש.

### לשוניות

- **הכל** — כל הפריטים בחשבון.  
- **שלי** — פריטים שמוקצים לכם.  
- **במעקב** — פריטים שאתם עוקבים אחריהם.  
- **הושלם** — פריטים שהסתיימו, באותה טבלה (אפשר עדיין לשנות סטטוס מהרשימה או מ־**⋯**). אין לוח בלשונית הזו, כי סטטוסים אחרים לא מופיעים כאן.

**הכל**, **שלי** ו**במעקב** משתפים ממשק אחד: עמודות לוח פתוח / בטיפול / ממתין/חסום / הושלם (גרירת כרטיסים משנה סטטוס), או טבלה אחת. לחיצה ימנית על כרטיס פותחת תפריט: פתיחה, העתקת קישור, סטטוס, מעקב, הקצה לי, ומחיקה. אייקון גריד/רשימה מחליף תצוגה; בכל שורה בטבלה **⋯** עם אותן פעולות. הלשוניות רק מסננות אילו פריטים מוצגים.

### דף פריט

פתחו `TASK-12` לעריכת כותרת וגוף, שינוי סטטוס/מוקצה/יעד, תוויות, והמשך הדיון. הפירוט הוא Markdown: **עריכה** מציגה את הסימון (כותרות `#`, רשימות, טבלאות); אחרי שמירה זה מוצג מעוצב. בטלפון פאנל הדיון בגובה קבוע בטווח כדי שאפשר יהיה לקרוא; במסך רחב הוא ליד הטופס. כמה תגובות ברצף מאותו אדם באותו יום (בלי שורת מערכת או דובר אחר באמצע) מתקבצות; האווטאר וקצה הבועה בהודעה האחרונה. הקלידו `@username` לאזכור בשרשור (הודעות בדיון לא שולחות מייל). הקלידו `#` בכותרת, בפירוט או בדיון לקישור בקונסול (`#mail/noreply@example.com/inbox`).

### תוויות

רק תוויות שמצורפות לפריט מוצגות כתגיות. **הוסף** פותח קטלוג עם חיפוש (כולל יצירה). בטבלה ובלוח תוויות עודפות מתקפלות ל־`+N`.

## אימייל

מי שביצע את השינוי **לא** מקבל מייל. שמירה אחת שולחת לכל היותר מייל אחד לנמען. צופים לא מקבלים מייל על סטטוס או תגובות.

מחרוזות מערכת (שמות סטטוס כמו פתוח / בטיפול / הושלם, סיכום השינוי ומעטפת המייל) לפי **שפת הנמען** בקונסול. כותרת, פירוט, תגובות ושמות משתמש נשארים כמו שנכתבו.

| שינוי | מי מקבל מייל |
|--------|----------------|
| נוצר (עם מוקצה) | המוקצה |
| נוצר (בלי מוקצה) | אף אחד |
| הוקצה / הוקצה מחדש | המוקצה החדש בלבד |
| בוטלה הקצאה | היוצר, אם הוא לא ביצע |
| סטטוס → `done` או `cancelled` | היוצר |
| סטטוס → `blocked` | היוצר והמוקצה |
| סטטוס אחר (פתוח ↔ בטיפול, ממתין, …) | אף אחד |
| תגובה / דיון | אף אחד |
| תאריך יעד / יעד קרוב | המוקצה, אחרת היוצר |
| נוסף צופה | המשתמש שנוסף |
| הוסר צופה | אף אחד |

שינויי קוסמטיקה (כותרת, פירוט, סוג, תוויות, עדיפות, פרויקט, קישור משאב) בלי מייל ובלי שורה בדיון. צופה שנוסף מקבל מייל, אבל לא נרשם בדיון.

מייל «יעד קרוב» נשלח פעם אחת כשהפריט יעד תוך 24 שעות ואינו הושלם/בוטל.

## קישורים בקונסול

הטקסט נשמר כרגיל. `#` מתחיל טוקן שירות עד רווח או סוף שורה. `@` בתוך הטוקן הוא חלק מהמשאב (למשל אימייל), לא אדם.

```text
#mail
#mail/noreply@holab.abrdns.com/inbox
#so/my-bucket/images
#so/my-bucket/images/logo.png
#compute/server-01
#mq/events
#mdb/prod-pg
#redis/cache-1
#fn/resize
#ir/api
#dns/example.com
#secrets/db-password
#iam/developers
#tasks/12
#k8s/default
#apps/web
#ssl/console-cert
#mon/cpu
#billing
```

- `#` — כינוי שירות (`mail`, `so`, `compute`, `mq`, `mdb`, `redis`, `fn`, `ir`, `dns`, `secrets`, `iam`, `tasks`, `k8s`, `apps`, `ssl`, `mon`, `billing`)
- `/` — משאב מהרשימה של השירות. ל-Mail גם תיקיות; ל-SO גם קידומות וקבצים.

השלמה אוטומטית לפי השלבים האלה. טוקן לא תקין נשאר טקסט רגיל. ל-`#billing` אין רשימת משאבים. IAM/SSL/Monitoring נפתחים בדף השירות כשאין דף פריט נפרד.

## הרשאות

| הרשאה | שימוש |
|--------|--------|
| `tasks.read` | לראות משימות בקטלוג ולפתוח פריטים |
| `tasks.create` | ליצור פריטים |
| `tasks.update` | סטטוס, הערות, תוויות בפריט, צופים |
| `tasks.delete` | למחוק פריטים |
| `tasks.manage_labels` | שינוי שם או ארכוב תוויות (API) |

בלי `tasks.read` אריח השירות מוסתר.

## טיפים

- משימות אינן **פרויקטים** של החשבון (תיקיות משאבים) ואינן **Operations** (עבודות provision).  
- אין פעמון התראות ב-V1 — בדקו **שלי** ואימייל.  
- דפי משימות פתוחים מתרעננים בזמן אמת כל עוד נשארים בדף.
