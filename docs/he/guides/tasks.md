# משימות (Tasks)

משימות הוא מעקב עבודה תפעולי לחשבון (שם המוצר: **Tasks**). משמש להקצאה, תאריכי יעד, סטטוסים, תוויות וקישורים ל-Compute / MDB / דומיינים — לא כתחליף ל-Jira.

| פריט | ערך |
|------|------|
| קונסול | **משימות** → `/console/tasks` |
| מפתחות | `TASK-{n}` לכל חשבון |
| אחסון | Postgres של מישור הבקרה (לא משאב Orchestrator) |
| התראה | אימייל דרך **noreply** של הפלטפורמה — רק למי שיש תפקיד בפריט |
| ממשק חי | רמז SSE מ-Realtime Gateway; REST הוא מקור האמת |

## בקונסול

### יצירה

1. פתחו **משימות** → **+ משימה**.  
2. כותרת, סוג, מוקצה אופציונלי, תאריך יעד אופציונלי.  
3. מדף פרטי Compute, MDB או דומיין, **+ משימה** ממלא את המשאב מראש.

תוויות, צופים ותיאור נמצאים בפאנל **פרטים** אחרי היצירה.

### לשוניות

- **הכל** — עמודות לוח: פתוח / בטיפול / ממתין/חסום / הושלם (גרירת כרטיסים משנה סטטוס). **רשימה** לטבלה.  
- **שלי** — פריטים שמוקצים לכם, לפי איחור / היום / בטיפול / ממתין / הושלמו לאחרונה.  
- **במעקב** — פריטים שאתם עוקבים אחריהם.  
- **הושלם** — פריטים שהסתיימו.

### דף פריט

פתחו `TASK-12` לסטטוס, מוקצה, יעד, שבב משאב, פעילות והערות. אזכור `@username` שולח אימייל לחבר החשבון.

### תוויות

מנהלים מנהלים את הקטלוג ב-`/console/tasks/labels`. מפתחים מצמידים/מסירים תוויות בפריט; הם לא משנים את הקטלוג.

## אימייל

מי שביצע את השינוי **לא** מקבל מייל. שמירה אחת שולחת לכל היותר מייל אחד לנמען.

| שינוי | מי מקבל מייל |
|--------|----------------|
| נוצר (עם מוקצה) | המוקצה |
| הוקצה / הוקצה מחדש | המוקצה החדש והקודם |
| בוטלה הקצאה | המוקצה הקודם והיוצר |
| שינוי סטטוס | מוקצה, יוצר, צופים |
| תגובה | אותם פלוס אזכורי `@username` |
| תאריך יעד / יעד קרוב | המוקצה, אחרת היוצר |
| נוסף צופה | המשתמש שנוסף |

שינויי קוסמטיקה (כותרת, תיאור, תוויות, קישורים) נרשמים בפעילות בלבד — בלי מייל.

מייל «יעד קרוב» נשלח פעם אחת כשהפריט יעד תוך 24 שעות ואינו הושלם/בוטל.

## הרשאות

| הרשאה | שימוש |
|--------|--------|
| `tasks.read` | לראות משימות בקטלוג ולפתוח פריטים |
| `tasks.create` | ליצור פריטים |
| `tasks.update` | סטטוס, הערות, תוויות בפריט, צופים |
| `tasks.delete` | למחוק פריטים |
| `tasks.manage_labels` | קטלוג תוויות |

בלי `tasks.read` אריח השירות מוסתר.

## טיפים

- משימות אינן **פרויקטים** של החשבון (תיקיות משאבים) ואינן **Operations** (עבודות provision).  
- אין פעמון התראות ב-V1 — בדקו **שלי** ואימייל.  
- דפי משימות פתוחים מתרעננים בזמן אמת כל עוד נשארים בדף.
